# React Vite Workspace

A minimal React application scaffolded for Vite and TypeScript.

## Setup

1. Install dependencies: `npm install`
2. Start local development server: `npm run dev`
3. Build for production: `npm run build`
4. Preview production build: `npm run preview`

## Notes

- Ensure Node.js and npm are installed before running commands.
- This workspace includes a TypeScript React starter and Vite configuration.
